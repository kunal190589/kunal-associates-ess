# Kunal Associates Workforce OS — V3 Employee Master + Face + QR

Added on top of V2 Attendance Engine while preserving the Figma visual language.

Modules:
- Employee Master directory
- Employee onboarding workflow
- Client/site deployment fields
- PF/ESI readiness indicators
- Face enrollment workflow
- QR employee I-Card preview
- QR refresh / print/export action placeholders
- Production security note for biometric templates

The face screen is a workflow/UI layer. Actual biometric matching requires a selected production SDK, secure backend, enrollment storage and identity verification service.
